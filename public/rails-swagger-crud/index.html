Demonstração: API REST de Posts (com Swagger simulado)

Crie, liste, edite e exclua posts. Todos os dados ficam salvos no localStorage do seu navegador — nenhum servidor externo.

Formulário · POST / PUT /api/v1/posts

GET POST PUT DELETE
Modo edição · ID:
[api/v1] Pronto. Os posts são salvos em localStorage na chave "rsc.posts.v1".

Listagem · GET /api/v1/posts

Swagger / OpenAPI 3 · spec simulada

O Rswag gera isso automaticamente a partir dos testes RSpec. Aqui está a aparência do contrato:

openapi: 3.0.1
info:
  title: rails-swagger-crud
  description: Posts API RESTful · TDD com Rswag + RSpec
  version: 1.0.0
paths:
  /api/v1/posts:
    get:
      summary: Lista todos os posts
      tags: [Posts]
      responses:
        '200': { description: OK }
    post:
      summary: Cria novo post
      requestBody:
        content:
          application/json:
            schema: { $ref: '#/components/schemas/PostInput' }
      responses:
        '201': { description: Criado }
        '422': { description: Erro de validação }
  /api/v1/posts/{id}:
    get:   { summary: Exibe um post }
    put:   { summary: Atualiza um post }
    delete:{ summary: Remove um post }
components:
  schemas:
    PostInput:
      type: object
      required: [title, body]
      properties:
        title:  { type: string,  example: Hello Swagger }
        author: { type: string,  example: Reinaldo B. }
        body:   { type: string,  example: Conteudo do post... }
        published: { type: boolean, example: true }
