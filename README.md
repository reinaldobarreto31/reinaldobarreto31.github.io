## 📲 Projeto em Destaque: Limpapp

O **Limpapp** é um aplicativo mobile nativo em desenvolvimento utilizando **Kotlin** e **Kotlin Multiplatform (KMP)** com interface em **Jetpack Compose** e backend em **Spring Boot 3**.

- **Diferencial:** Fluxo de captura e envio de **fotos ilustrativas** dos serviços realizados (antes/depois), permitindo ao profissional montar seu portfólio visual direto no app e ao cliente acompanhar os atendimentos.
- **Upload interativo:** Disponível diretamente no card do Limpapp no portfólio e no Painel Administrativo.
